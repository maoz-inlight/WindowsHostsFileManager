# Hosts Manager 1.0.16

- Choose a color and optional name for isolated Chrome and Edge previews, with preset
  colors and a custom color picker. Edit saved profiles through **Browser preview data →
  Name & color**. The active-preview banner shows the selected color and hex code.
- Keep your chosen name and color when changing browser flags. Remember the last selected
  browser across dialogs and app restarts.
- Check background processes for the selected preview profile instead of blocking on all
  Chrome/Edge processes. **Close background preview** stops a selected profile's remaining
  background processes after confirmation; visible preview windows must be closed normally.
- Use generated browser themes for reliable color selection in the tested Chrome and Edge
  versions. Browser themes derive light/dark shades from the selected color; private windows
  may ignore it.

Validation: 232 tests passed, desktop build succeeded, and the user confirmed the corrected
color selection works. All three architectures are packaged; native installation/upgrade/
uninstall across all architectures remains outside this validation.
